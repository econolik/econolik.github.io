ℹ️ Как считается
  • Прогресс — доля разных пройденных тем из 26.
  • Ср. балл — считается по выбранному правилу — среднее / лучшая / последняя попытка (переключатель «Как считать балл» над таблицей).
  • Тем пройдено — сколько из 26 тем ученик открывал в тесте.
  • Активность — когда в последний раз проходил тест.

Данные появляются, когда ученик вошёл по коду и завершил тест (гость не считается).
